# Dupe / Clone Mapping Reference (Research Step 1)

> This file is research step 1 for the Scentarchy dupe database. It is a human-verified research reference only. No database import has been done; a separate import step will map these entries into the DB schema later.

**Methodology.** Every mapping below was checked against fragrance-community consensus (Fragrantica "this perfume reminds me of" polls, r/fragrance, r/DesiFragranceAddicts, YouTube reviewers, and dupe-reference sites such as whatscent, fragrary, scentclones, osmoz, equivalenzaprofumi, altscent) via web search on 2026-10-17. Only genuinely well-known mappings are included; nothing was invented. Entries marked **[unverified]** rest on a single weak source and must be re-checked before DB import. Where no dominant clone exists, that is stated plainly instead of inventing one.

**House priority.** Indian and Middle Eastern houses with Indian distribution are listed first (Armaf, Lattafa, Al Haramain, Rasasi, Ajmal, Fragrance World, Paris Corner, Maison Alhambra, Afnan, Rayhaan, Khadlaj, Zimaya, Arabiyat Prestige, Bujairami, Swiss Arabian, Ahmed Al Maghribi, No Name Perfume, 6666 Perfumes, Art of Aroma). Notable global dupes (Dua, Alexandria, Dossier, Zara) are included where genuinely well known.
